This organization contains all the important repositories required to build custom ROMs for the Xiaomi Pad 8 (yupei)

### Required device specific repositories
* [**Device tree**](https://github.com/xiaomi-pad-8-development/android_device_xiaomi_yupei) (`android_device_xiaomi_yupei`)
* [**Device prebuilt kernel tree**](https://github.com/xiaomi-pad-8-development/android_device_xiaomi_yupei-kernel) (`android_device_xiaomi_yupei-kernel`)
* [**Proprietary blobs tree**](https://gitlab.com/sidharthify/android_vendor_xiaomi_yupei) (`android_vendor_xiaomi_yupei`)

### Device kernel repositories
* [**Kernel source**](https://github.com/xiaomi-pad-8-development/android_kernel_xiaomi_yupei) (`android_kernel_xiaomi_yupei`)

Maintained and lead by @sidharthify
